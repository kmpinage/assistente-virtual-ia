# Assistente Virtual IA (Projeto Jarvis) 

Este repositório contém o código de um assistente virtual interativo construído em Python, focado em **Prompt Engineering** e **Orquestração de Agentes**. 

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Integração de APIs de IA:** (OpenAI e Gemini)
* **Bibliotecas:** (Ex: SpeechRecognition, pyttsx3, requests, etc.)

## ⚙️ Funcionalidades
* Processamento de linguagem natural para respostas dinâmicas.
* Automação de tarefas e consultas de informações em tempo real.
* Interação por voz.

## 💡 Objetivo
Projeto desenvolvido para explorar a aplicação prática de LLMs, criação de agentes autônomos e automação de rotinas (Vibe Coding).
